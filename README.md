# U.F.O. Duel

A browser-based Rock Paper Scissors game with Classic and Rock Paper Scissors Lizard Spock modes.

## Run the game

Open `index.html` in a web browser. Choose a game mode, select a move, and click the game button to play.

The Settings screen lets you enter a player name and choose the number of wins needed to finish a duel.

## Project files

- `index.html` contains the game screens and controls.
- `style.css` styles the game.
- `script.js` contains the game logic.
- `background.svg` provides the background illustration.
